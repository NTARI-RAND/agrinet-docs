# वेबसाइट

यह वेबसाइट [Docusaurus](https://docusaurus.io/) का उपयोग करके बनाई गई है, जो एक आधुनिक स्टैटिक वेबसाइट जनरेटर है।

## इंस्टॉलेशन

```bash
yarn
```

## स्थानीय विकास

```bash
yarn start
```

यह कमांड एक स्थानीय डेवलपमेंट सर्वर शुरू करता है और एक ब्राउज़र विंडो खोलता है। अधिकांश बदलाव सर्वर को पुनः आरंभ किए बिना तुरंत (लाइव) दिखाई देते हैं।

## बिल्ड

```bash
yarn build
```

यह कमांड `build` डायरेक्टरी में स्टैटिक सामग्री तैयार करता है, जिसे किसी भी स्टैटिक सामग्री होस्टिंग सेवा के माध्यम से सर्व किया जा सकता है।

## डिप्लॉयमेंट

SSH का उपयोग करते हुए:

```bash
USE_SSH=true yarn deploy
```

SSH का उपयोग किए बिना:

```bash
GIT_USER=<Your GitHub username> yarn deploy
```

यदि आप होस्टिंग के लिए GitHub pages का उपयोग कर रहे हैं, तो यह कमांड वेबसाइट को बिल्ड करने और `gh-pages` ब्रांच पर पुश करने का एक सुविधाजनक तरीका है।

## खोज कॉन्फ़िगरेशन

साइट में एक स्थानीय दस्तावेज़ीकरण खोज शामिल है जो किसी भी बाहरी सेवा के बिना काम करती है, ताकि स्थानीय विकास और प्रीव्यू डिप्लॉयमेंट में हमेशा एक काम करने वाला सर्च बार मौजूद रहे। जब वास्तविक Algolia DocSearch क्रेडेंशियल मौजूद होते हैं, तो हम स्वचालित रूप से Algolia पर स्विच कर जाते हैं। Ask AI अब अलग से कॉन्फ़िगर किया जाता है, ताकि आप जो क्रेडेंशियल देते हैं उनके आधार पर Ask AI के बिना Algolia खोज, या इसका उलटा, सक्षम कर सकें। Algolia-संचालित अनुभव React.dev से प्रेरित एक पिल (pill) ट्रिगर अपनाता है, जिसमें एक समर्पित Ask AI बैज होता है, ताकि आगंतुकों को तुरंत पता चल जाए कि संवादात्मक उत्तर कब उपलब्ध हैं।

Algolia खोज और Ask AI को सक्षम करने के लिए निम्नलिखित मानों के साथ एक `.env` फ़ाइल बनाएँ (या अपने शेल में वेरिएबल एक्सपोर्ट करें):

```bash
ALGOLIA_APP_ID="..."
ALGOLIA_API_KEY="..."          # Search-only API key
ALGOLIA_INDEX_NAME="..."

# Optional Ask AI configuration
ALGOLIA_ASSISTANT_ID="..."     # Algolia Ask AI assistant identifier

# Optional overrides if your Ask AI integration uses a dedicated application or index
# ALGOLIA_AI_APP_ID="..."
# ALGOLIA_AI_API_KEY="..."
# ALGOLIA_AI_INDEX_NAME="..."
```

Ask AI वेरिएबल केवल तभी सेट करें जब आपका DocSearch एप्लिकेशन इस अनुभव के लिए कॉन्फ़िगर किया गया हो; अन्यथा उन्हें बिना सेट किए छोड़ा जा सकता है। इन वेरिएबल के बिना, साइट Ask AI को सक्रिय करने का प्रयास किए बिना शामिल स्थानीय दस्तावेज़ीकरण खोज (या, यदि वे क्रेडेंशियल दिए गए हों, तो Algolia) का ही उपयोग करती रहती है। जब Algolia क्रेडेंशियल और एक Ask AI असिस्टेंट दोनों मौजूद होते हैं, तो कॉन्फ़िगरेशन स्वचालित रूप से असिस्टेंट को DocSearch से जोड़ देता है, ताकि मोडल ठीक React.dev अनुभव की तरह संवादात्मक पैनल दिखा सके। Algolia क्रेडेंशियल देते हुए भी Ask AI फ़ील्ड खाली छोड़ने पर पारंपरिक, केवल-DocSearch वाला UI मिलता है।
