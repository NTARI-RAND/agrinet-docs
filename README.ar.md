# الموقع الإلكتروني

بُني هذا الموقع باستخدام [Docusaurus](https://docusaurus.io/)، وهو مولّد حديث للمواقع الثابتة.

## التثبيت

```bash
yarn
```

## التطوير المحلي

```bash
yarn start
```

يشغّل هذا الأمر خادم تطوير محليًا ويفتح نافذة متصفح. وتظهر معظم التغييرات مباشرةً دون الحاجة إلى إعادة تشغيل الخادم.

## البناء

```bash
yarn build
```

يولّد هذا الأمر محتوى ثابتًا في المجلد `build`، ويمكن تقديمه باستخدام أي خدمة لاستضافة المحتوى الثابت.

## النشر

باستخدام SSH:

```bash
USE_SSH=true yarn deploy
```

دون استخدام SSH:

```bash
GIT_USER=<Your GitHub username> yarn deploy
```

إذا كنت تستخدم GitHub Pages للاستضافة، فإن هذا الأمر طريقة ملائمة لبناء الموقع ودفعه (push) إلى الفرع `gh-pages`.

## إعداد البحث

يتضمّن الموقع بحثًا محليًا في التوثيق يعمل دون أي خدمات خارجية، بحيث تتضمّن بيئة التطوير المحلية وعمليات نشر المعاينة دائمًا شريط بحث يعمل. وعند توفّر بيانات اعتماد حقيقية لـ Algolia DocSearch، ننتقل تلقائيًا إلى Algolia. أصبحت ميزة Ask AI الآن تُضبط بشكل منفصل، بحيث يمكنك تفعيل بحث Algolia دون Ask AI أو العكس، بحسب بيانات الاعتماد التي تقدّمها. وتعتمد التجربة المدعومة من Algolia زرّ تشغيل على شكل حبّة (pill) مستوحى من React.dev، مع شارة مخصّصة لـ Ask AI، حتى يكتشف الزوّار فورًا متى تكون الإجابات الحوارية متاحة.

أنشئ ملف `.env` (أو صدِّر المتغيرات في الصدفة (shell) الخاصة بك) بالقيم التالية لتفعيل بحث Algolia وAsk AI:

```bash
ALGOLIA_APP_ID="..."
ALGOLIA_API_KEY="..."          # Search-only API key
ALGOLIA_INDEX_NAME="..."

# Optional Ask AI configuration
ALGOLIA_ASSISTANT_ID="..."     # Algolia Ask AI assistant identifier

# Optional overrides if your Ask AI integration uses a dedicated application or index
# ALGOLIA_AI_APP_ID="..."
# ALGOLIA_AI_API_KEY="..."
# ALGOLIA_AI_INDEX_NAME="..."
```

لا تضبط متغيرات Ask AI إلا عندما يكون تطبيق DocSearch الخاص بك مُعدًّا لهذه التجربة؛ وإلا فيمكن تركها دون تعيين. ومن دون هذه المتغيرات، يواصل الموقع استخدام البحث المحلي المضمَّن في التوثيق (أو Algolia، إذا قُدّمت بيانات الاعتماد الخاصة به) دون محاولة تفعيل Ask AI. وعندما تتوفّر بيانات اعتماد Algolia ومساعد Ask AI معًا، يربط الإعداد المساعدَ تلقائيًا بـ DocSearch بحيث يمكن للنافذة المنبثقة (modal) أن تُظهر اللوحة الحوارية تمامًا كما في تجربة React.dev. أمّا ترك حقول Ask AI فارغة مع تقديم بيانات اعتماد Algolia فينتج عنه واجهة DocSearch التقليدية وحدها.
